# `.ai/` — 项目共享知识库

面向两类读者：接手这个项目的下一个人，以及帮 TA 干活的 AI。

这个项目目前处于**设计阶段**——还没有代码。这里真正"贵"的不是花了几个小时才查出来的bug，而是一整轮设计讨论里做出的架构判断——如果不写下来，就只会留在聊天记录里。

## 这里有什么

| 路径 | 存放内容 | 生命周期 |
|---|---|---|
| [architecture.md](architecture.md) | 当前达成一致的系统设计：数据流、隔离模型、文件结构 | 跟随设计演进 |
| [decisions/](decisions/) | 做过的选择、被否掉的方案输在哪、什么情况下会推翻 | 可逆——原地编辑 |
| [handoff.md](handoff.md) | 现在进展到哪、下一步具体做什么 | **设计上就是会过期的** |

暂时没有 `debug/` 或 `memory/`——还没有代码或者值得共享的反复出现的事实，等有了第一条真实内容再建。

## 新信息该往哪儿放

| 你观察到的 | 写到哪 | 判断标准 |
|---|---|---|
| 做了一个设计选择，否掉了别的方案 | `decisions/` | 能写出"为什么不选另一个" |
| 系统现在的样子 | `architecture.md` | 下一次设计微调后依然成立，否则就更新它 |
| 进展、待定问题、下一步 | `handoff.md` | 它会过期 |
| 这个用户喜欢怎么被协作 | 本地 AI 记忆，不放这个仓库 | 是关于人的，不是关于项目的 |
